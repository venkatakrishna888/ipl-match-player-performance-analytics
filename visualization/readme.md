# IPL Match & Player Performance Analytics

## Project Overview
This project analyzes IPL cricket data using Python, SQL, Machine Learning, and Streamlit.

The system provides:
- Team analysis
- Player analysis
- Venue analysis
- Toss impact analysis
- Strike rate analysis
- Powerplay & death overs analysis
- Match winner prediction

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Streamlit
- MySQL
- Scikit-learn

## Features
- Interactive dashboard
- Data visualization
- SQL analytics
- Machine learning prediction
- Sports analytics insights

## Machine Learning
Implemented Random Forest model for IPL match winner prediction.

## Dashboard
Built using Streamlit with interactive filters and visualizations.
